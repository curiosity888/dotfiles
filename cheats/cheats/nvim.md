# nvim — рецепты

Бинды не здесь: `:Telescope keymaps` (или `<leader>ff` по конфигу). Тут — грамматика и многошаговые приёмы.

## Грамматика: оператор + объект

Операторы: `c` заменить, `d` удалить, `y` скопировать, `v` выделить, `>` сдвинуть, `gU`/`gu` — регистр.

| Объект | Что это |
|---|---|
| `iw` / `aw` | слово / слово с пробелом |
| `i"` `i'` `` i` `` | внутри кавычек (`a"` — с кавычками) |
| `i(` `i{` `i[` | внутри скобок (`a(` — со скобками) |
| `it` / `at` | внутри html-тега / с тегом |
| `ip` / `ap` | абзац |

Комбинируется всё со всем: `ci"` — заменить внутри кавычек, `da{` — удалить блок со скобками, `yap` — скопировать абзац, `gUiw` — слово в верхний регистр.

Курсору не обязательно стоять внутри: `ci(` найдёт ближайшие скобки на строке.

## Substitute и vim-регексы

```vim
:%s/old/new/g          " по всему файлу
:'<,'>s/old/new/g      " по выделению (диапазон подставится сам)
:%s/old/new/gc         " с подтверждением каждой замены
:%s//new/g             " old = последний поиск (удобно: сначала ищешь /old)
```

Группы захвата — включай `\v` (very magic), чтобы не экранировать скобки:

```vim
:%s/\v(\d+)-(\d+)/\2-\1/g        " 12-34 → 34-12
:%s/\v^(\w+),(\w+)$/\2,\1/       " поменять колонки местами
```

В замене: `\1`, `\2` — группы, `\0` — всё совпадение, `\U\1` — в верхний регистр, `&` — тоже всё совпадение.

## :g — команда на строки по паттерну

```vim
:g/DEBUG/d             " удалить все строки с DEBUG
:v/keep/d              " удалить все строки БЕЗ keep (v = инверсия)
:g/^$/d                " удалить пустые строки
:g/TODO/norm A  !!!    " дописать в конец каждой TODO-строки
:g/^SELECT/norm gUU    " все строки с SELECT — в верхний регистр
```

`:g/паттерн/КОМАНДА` = выполнить ex-команду на каждой подходящей строке.

## Макросы

```
qa  →  ...правки...  →  q      " записать в регистр a
@a                              " выполнить
15@a                            " 15 раз
@@                              " повторить последний
:'<,'>norm @a                   " на каждой строке выделения
```

Если макрос «сломался» на середине — он просто останавливается, это нормально: ошибка (нет совпадения, конец файла) прерывает выполнение.

`:norm` работает и без макроса: `:'<,'>norm A;` — дописать `;` в конец каждой выделенной строки.

## Замена по всему проекту (telescope + quickfix)

```
<leader>ps → ввести паттерн        " live grep по проекту
Ctrl+Q                              " все результаты → quickfix
:cdo s/old/new/g | update           " замена в каждом результате + сохранить
```

Навигация по quickfix: `:cnext` / `:cprev`, список — `:copen`.

## Массовые правки

```vim
:sort                  " отсортировать строки (выделение или %)
:sort u                " + убрать дубли
:sort n                " числовая сортировка
Ctrl+A / Ctrl+X        " +1 / -1 к числу под курсором
g Ctrl+A               " в выделении: 1,1,1 → 1,2,3 (нумерация)
```

Вертикальное выделение: `Ctrl+V` → выделить колонку → `I` (вставить в начало) или `A` (в конец) → текст → `Esc` — применится ко всем строкам.

## Откат и история

```vim
u / Ctrl+R             " undo / redo
:earlier 5m            " файл как 5 минут назад
:later 5m              " обратно
<leader>u              " undotree: дерево всех веток истории
Ctrl+O / Ctrl+I        " назад/вперёд по местам переходов (в т.ч. между файлами)
gv                     " восстановить последнее выделение
`.                     " прыгнуть к последней правке
```

## SQL-специфичное (dbee)

```
<leader>dr             " выполнить файл (в visual — только выделение)
```

Плюс связка: `vip` — выделить query-абзац → `<leader>dr` — выполнить его.
