# tmux — мои бинды

Prefix: `Ctrl+Space` (запасной `Ctrl+B`). Всё ниже с `⌥` — без префикса (Alt).

## Сессии

| Клавиши | Действие |
|---|---|
| `prefix f` | **Сессионайзер**: выбрать проект через fzf (создаст сессию, если нет) |
| `prefix S` | Переключение между живыми сессиями через fzf |
| `prefix s` | Встроенное дерево сессий (`x` — убить, `t` — пометить, `X` — убить помеченные) |
| `⌥Up` / `⌥Down` | Предыдущая / следующая сессия |
| `prefix R` | Переименовать сессию |
| `prefix C` | Новая сессия (в текущей папке) |
| `prefix K` | Убить текущую сессию |

## Окна

| Клавиши | Действие |
|---|---|
| `prefix c` | Новое окно (в текущей папке) |
| `prefix k` | Убить окно |
| `prefix r` | Переименовать окно |
| `⌥1..9` | Перейти к окну N |
| `⌥Left` / `⌥Right` | Соседнее окно |
| `⌥Shift+Left/Right` | Передвинуть окно влево/вправо |

## Панели

| Клавиши | Действие |
|---|---|
| `prefix h` | Сплит горизонтальный (панель снизу) |
| `prefix v` | Сплит вертикальный (панель сбоку) |
| `prefix x` | Убить панель |
| `Ctrl+⌥+стрелки` | Перейти между панелями |
| `Ctrl+⌥+Shift+стрелки` | Изменить размер панели |
| `prefix b` | Панель → отдельное окно |
| `prefix B` | Панель → окно на позицию N |
| `prefix j` | Втянуть окно N как панель сюда |
| `prefix m`, потом `prefix J` | Пометить панель и втянуть её сюда |

## Copy mode (vi)

| Клавиши | Действие |
|---|---|
| `prefix [` | Войти в copy mode |
| `v` | Начать выделение |
| `y` | Скопировать и выйти |
| `q` | Выйти без копирования |

## Прочее

| Клавиши | Действие |
|---|---|
| `prefix g` | Эта шпаргалка (cheat); внутри `Ctrl+G` — режим grep |
| `prefix G` | Шпаргалки: сразу grep по содержимому |
| `prefix q` | Перечитать конфиг |
| `prefix d` | Отцепиться от сессии (всё продолжает работать) |

## CLI-шпаргалка

```bash
tmux ls                      # список сессий
tmux attach -t имя           # подключиться
tmux kill-session -t имя     # убить сессию
tmux kill-session -a         # убить все, кроме текущей
tmux kill-server             # убить всё (сессии не восстановятся!)
```
